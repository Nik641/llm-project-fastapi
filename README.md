# llm-project-fastapi

## Основной функционал

Интеграция с OpenAI: отправка промптов и получение ответов от модели gpt-4.

Асинхронный API: быстрая обработка запросов благодаря FastAPI.

Логирование в БД: автоматическое сохранение истории запросов и ответов от LLM в базу данных SQLite.

Интерактивная документация: автоматическая генерация Swagger UI (/docs) для тестирования эндпоинтов.

## Стек технологий

Backend: Python, FastAPI, Uvicorn

LLM: OpenAI API (GPT-4)

Database: SQLite, SQLAlchemy
